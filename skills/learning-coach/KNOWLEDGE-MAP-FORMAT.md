# KNOWLEDGE-MAP.md 格式

Written in Phase 2, appended in Phase 3. One file per topic.

```markdown
# <主題> 知識地圖

建立日期：YYYY-MM-DD ｜ 資料來源：<書／課程／論文，逐項列出>

## 核心概念

### 1. <概念名稱>
- **定義**：<一句話。用使用者程度聽得懂的語言，不是教科書原文>
- **與其他概念的關係**：<依賴誰？被誰依賴？跟哪個概念容易混淆？>
- **實際例子**：<來自使用者提供的資料，標【資料】；自己補的標【外部】>

（5–10 個）

## 依賴階梯

基礎
  └─ <概念>、<概念>
核心概念
  └─ <概念>、<概念>
進階概念
  └─ <概念>
實際應用
  └─ <概念>
專家級思考
  └─ <概念>

- **前置知識（先學）**：<列出，並說明「不先懂這個，下面全部會誤解」的理由>
- **可以之後再學**：<列出，並說明為什麼現在跳過不影響理解>

## 思維模型

### 模型 1：<名稱>
- **模型是什麼**：
- **為什麼重要**：<不用這個模型會犯什麼錯>
- **什麼情況使用**：<具體觸發條件>
- **常見誤用**：<新手怎麼用錯>

（5 個）

## 專家爭議

### 爭議 1：<問題是什麼>
- **觀點 A**：<最強論據，用 A 陣營最有說服力的版本，不是稻草人>
- **觀點 B**：<最強論據>
- **雙方依據**：A 依據 <資料／前提／價值取捨>；B 依據 <…>
- **A 較合理的情境**：
- **B 較合理的情境**：
- **判斷準則**：<專業人士遇到新案子時，用什麼問題決定走 A 還走 B>

（3 個）
```

## 規則

- 論據要用該陣營最強的版本。寫成稻草人等於沒寫。
- 判斷準則必須能套用到雙方都沒討論過的新案例，否則只是換句話說的選邊站。
- 資料裡沒有真實爭議就直說，不要編造。
