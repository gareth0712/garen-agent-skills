# 結業報告格式

輸出在一個學習階段結束時。全部欄位都要有具體內容，不留空。

```markdown
# <主題> 學習階段報告

期間：YYYY-MM-DD ～ YYYY-MM-DD ｜ 測驗輪數：n ｜ 錯題庫條目：n

## 🗺️ 我的知識地圖

**已掌握**（🟢，不同案例連續答對）
- <概念> — <一句話說明他能做到什麼，不是「他知道 X」>

**需要補強**（🔴🟠🟡）
- <概念>（🟠）— 斷點：<從 X 推到 Y 時跳過 Z>

## 🧠 我的核心思維模型

**真正理解**
- <模型> — 證據：<他在哪一題主動用了這個模型，不是被提示才用>

**還在背名詞**
- <模型> — <他答得出定義，但遇到 <情境> 沒有拿出來用>

## 🔥 我理解的專家爭議

- <爭議> — 他能說明雙方最強論據，並判斷 <某新案例> 該走哪邊
- <爭議> — 仍只能覆述立場，說不出判斷準則

## 🐛 我的高頻錯誤

以錯題庫中反覆出現的**推理模式**排序，不是以概念排序：
1. <錯誤模式，例如「把相關當成因果」> — 出現在 <概念 A>、<概念 C>、<概念 F>
2. …

## 📈 我的理解程度

| 面向 | 分數 | 依據 |
|------|:----:|------|
| 基礎概念 | _/10 | <哪幾題> |
| 概念連結 | _/10 | |
| 實際應用 | _/10 | |
| 推理能力 | _/10 | |
| 專家級理解 | _/10 | |

## 🎯 下一階段

只有 3 件事：
1. <最值得學的一件> — 因為 <它擋住了哪些後續概念>
2. …
3. …
```

## 規則

- **分數要有依據。** 每一格後面接「哪幾題答對／答錯」，否則是憑感覺打分。
- **高頻錯誤按推理模式分類。** 「三個概念都錯」不如「同一種因果誤判出現三次」有用——後者才修得掉。
- **下一階段只列 3 件。** 一次塞一堆等於沒排序。
