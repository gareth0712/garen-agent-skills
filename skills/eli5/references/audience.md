# Audience calibration

Adapted from [dreambigou/eli5](https://github.com/dreambigou/eli5) (MIT License,
Copyright (c) 2026). Changed: the default audience is **not** "age 5" here, and every
row still obeys the six rules in `SKILL.md` - the tables change vocabulary, tone and
analogy, never whether the example comes first.

**Default when no reader is named:** a careful colleague who knows the domain but did
not watch the work. Real table and column names are fine; anything decided during the
session is not shared context and must be shown.

## Job roles

| Reader | They care about | Build the example around |
|--------|-----------------|--------------------------|
| Product manager | User value, priorities, scope | A named user doing one flow, with the numbers they see on screen |
| Manager / director | Impact, timeline, risk, cost | How many users or dollars, over what window, and the decision being asked |
| Tech lead / engineer | How it works, trade-offs | Literal rows, the literal query or call, a lock or request timeline |
| Designer | User experience, flow | The screen state before and after, the exact copy shown |
| Legal / compliance | Exposure, wording, who is bound | The exact sentence a user reads, and what happens to their money or data |
| Colleague / reviewer | What changes in their work | The input that behaves differently and the before/after output |
| New hire | Where things are and why | The literal command, its output, the file it touched |

## Ages and education levels

| Reader | Style |
|--------|-------|
| Age 5-10 | Short sentences, toys, school, games. The example is a story with one character |
| Age 15 | Some abstraction, phone and gaming references, slightly casual |
| Adult, non-technical | Daily life, work, money. Define every term by showing it |
| College student | Technical terms with brief context, theory plus one worked case |
| Graduate / expert | Precise terms; spend the words on edge cases and trade-offs, still with literal values |

## Relationships

| Reader | Tone | Analogy source |
|--------|------|----------------|
| Partner | Warm, conversational | Household tasks, shared routines |
| Parent | Respectful, no condescension | Technology they already use, home analogies |
| Child | Playful, short | Games, cartoons, animals |
| Friend | Casual | Shared interests, "you know how..." |

## What never changes

- Example first, rule second.
- Bad case beside good case, same input.
- Real numbers, real names, the reader's language.
- Never talk down: a simple explanation should feel clear, not dumbed down.
